# GrxDiscover - Your Interactive Guide to Granada

**GrxDiscover** is a web application designed for both tourists and locals to discover the treasures of Granada in a modern, interactive way.

[**Visit the live application**](https://grxdiscover.cclouud.com)

---

## 🌟 About the Project

The idea behind GrxDiscover is simple: to provide a centralized, easy-to-use tool for exploring everything Granada has to offer. From the most iconic monuments to the most hidden tapas bars, our platform helps you plan your next adventure in the city.

This project serves as a demonstration of skills and a portfolio piece, showcasing how various technologies can be integrated to create a finished product.

---

## ✨ Key Features

-   **🗺️ Interactive Map:** A detailed map of Granada (using Leaflet.js) where you can view the locations of hundreds of places, filtered by category.
-   **🔍 Search and Filters:** Find exactly what you're looking for. Filter by **restaurants**, **monuments**, **leisure**, or **tourist routes**.
-   **⭐ Favorites:** Log in to save your favorite spots and keep them handy.
-   **✍️ User Reviews:** Read opinions from other explorers or leave your own to help the community.
-   **📸 Image Gallery:** Each place features images so you know what to expect, integrating APIs like Unsplash.
-   **🌓 Light & Dark Theme:** Change the web's appearance to suit your preference or ambient light.
-   **📱 Fully Responsive Design:** Enjoy the same experience on your computer as on your mobile device.

---

## 🛠️ Technologies Used

This project was made possible by combining the following technologies:

-   **Frontend:** HTML5, CSS3, JavaScript (ES6+), and Leaflet.js.
-   **Backend:** PHP for server-side logic.
-   **Database & Authentication:** [Supabase](https://supabase.com), the open-source alternative to Firebase.
-   **Hosting:** Deployed on [Render](https://render.com).
